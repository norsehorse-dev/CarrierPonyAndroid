CarrierPony: приватный мессенджер и приложение для безопасной передачи файлов с настоящим сквозным PGP-шифрованием. Без номера телефона. Без email. Без аккаунта. Только вы, люди, которым вы доверяете, и шифрование, которое действительно работает.

ПОЧЕМУ CARRIERPONY?

Большинство «защищённых мессенджеров» по-прежнему просят номер телефона и хранят ваш список контактов. CarrierPony не просит ничего. Ваша личность определяется парой ключей OpenPGP, созданной на вашем устройстве, и закрытый ключ никогда его не покидает.

НАСТОЯЩЕЕ PGP-ШИФРОВАНИЕ
* Каждое сообщение и каждый файл защищены сквозным шифрованием OpenPGP
* Сообщения шифруются на вашем устройстве и расшифровываются только на устройстве собеседника
* Сервер-ретранслятор пересылает только запечатанные конверты: без имён, без содержимого, без открытого текста
* В основе лежит PGPonyCore, наш криптографический движок с открытым исходным кодом, который может проверить любой

БЕЗ АККАУНТОВ И СЛЕЖКИ
* Не нужны номер телефона, email или регистрация
* Никакой загрузки списка контактов, рекламы, аналитики и трекеров
* Ретранслятор видит только случайный идентификатор, созданный при установке

БЕЗОПАСНАЯ ПЕРЕДАЧА ФАЙЛОВ
* Отправляйте фото, документы и файлы любого типа со сквозным шифрованием
* Файлы никогда не загружаются в читаемом виде и никогда не сканируются

СОПРЯЖЕНИЕ ПО QR-КОДУ
* При встрече: одно сканирование QR-кода связывает оба телефона
* Удалённо: отправьте приглашение по любому каналу, которому доверяете
* Проверяйте контакты по коду безопасности

ВСЁ ПОД ВАШИМ КОНТРОЛЕМ
* Исчезающие сообщения с отдельным таймером для каждого разговора
* Блокировка приложения отпечатком пальца или распознаванием лица
* Зашифрованные резервные копии личности, защищённые парольной фразой, которую знаете только вы
* Личные псевдонимы для контактов, которые видите только вы
* Сброс и удаление всех данных в любой момент

РЕТРАНСЛЯТОРЫ И СЕТЬ
* По умолчанию запечатанные сообщения проходят через ретранслятор CarrierPony по адресу api.carrierpony.com
* Разверните собственный CarrierPony-Relay и укажите его в приложении: Настройки > Ретранслятор
* Необязательный транспорт Nostr, по умолчанию выключен: если его включить, каждое запечатанное сообщение также публикуется на сторонних ретрансляторах Nostr (по умолчанию relay.damus.io и nos.lol). Эти ретрансляторы видят нечитаемое содержимое и ваш IP-адрес

CarrierPony входит в семейство приложений для приватности Pony вместе с PGPony (OpenPGP на вашем телефоне), AgePony, QuorumPony и RelayPony.
